حریم خصوصی و اطلاعات کاربران

این صفحه توضیح می‌دهد اطلاعاتی که از طریق فرم‌های سایت Borhan_SK ارسال می‌کنی چگونه استفاده و نگهداری می‌شود.

چه اطلاعاتی دریافت می‌شود؟

  • در فرم سفارش: نام، ایمیل، آیدی تلگرام اختیاری، نوع پروژه، محدوده بودجه، زمان موردنظر، توضیحات و فایل پیوست اختیاری.
  • در فرم پیام: نام، ایمیل، موضوع و متن پیام.
  • در بخش دیدگاه‌ها: نام، نوع دیدگاه و متن آن.

اطلاعات چگونه استفاده می‌شود؟

اطلاعات فقط برای بررسی درخواست، برآورد پروژه، پاسخ‌گویی، پشتیبانی و نمایش دیدگاه‌هایی که مالک تأیید کرده است استفاده می‌شود. اطلاعات تماس و سفارش‌ها در پنل عمومی نمایش داده نمی‌شوند.

فایل‌ها و دسترسی

پیوست‌های ارسالی در فضای خصوصی ذخیره می‌شوند و فقط مالک سایت به آن‌ها دسترسی دارد. فایل تحویل پروژه ممکن است با یک لینک موقت و امضاشده برای مشتری ارسال شود.

ذخیره‌سازی و حذف اطلاعات

اطلاعات در پایگاه داده Supabase نگهداری می‌شود. برای درخواست اصلاح یا حذف اطلاعات، از راه‌های ارتباطی درج‌شده در صفحه اصلی پیام بفرست.

سرویس‌های فنی

وب‌سایت به‌صورت فایل‌های استاتیک میزبانی می‌شود و برای دیتابیس، احراز هویت مالک و ذخیره فایل‌ها از Supabase استفاده می‌کند. کلید عمومی Supabase در مرورگر قابل مشاهده است، اما دسترسی داده‌ها با سیاست‌های امنیتی پایگاه داده محدود شده است.

Privacy & User Data

This page explains how information submitted through Borhan_SK forms is used and stored.

What information is collected?

  • Project requests: name, email, optional Telegram username, project type, budget range, expected timeline, description, and optional attachment.
  • Contact messages: name, email, subject, and message.
  • Feedback: name, feedback type, and message.

How is information used?

Information is used only to review project requests, prepare estimates, reply to messages, provide support, and publish feedback approved by the site owner. Contact details and project requests are never shown in the public website.

Files and access

Customer attachments are stored in private storage and are accessible only to the site owner. Project deliverables may be shared with customers through temporary signed links.

Retention and deletion

Information is stored in Supabase. To request correction or deletion, contact the site owner through the channels listed on the homepage.

Technical providers

The website is served as static files. Supabase provides the database, owner authentication, and file storage. The public Supabase key is visible in the browser, while database access is restricted by Row Level Security policies.
